# 13｜教师后训练（传统 LLM 微调） vs 教师进化：旧想法与共进化方案的严格比较

> 归档：早期方案——“教师用传统 LLM 训练（SFT/后训练），数据=证明搜索 rollout+新增 mathlib 定理/引理，低频更新”——与上一文档（教师进化/共进化）的比较分析。

## 0. 两条路的形式化

设教师为 $\tau$，学生为 $\theta$，经验集 $D_t = \{\text{学生 rollout}\}\cup\{\text{入库定理/引理}\}\cup\{\text{失败模式摘要}\}$。

- **教师进化（上一方案，记为 A）**：$\tau$ 是配置向量（prompt/规则/算子权重），更新在**推理层壳**里发生：

$$\tau_{t+1} = \mathrm{evolve}\big(\tau_t;\ \mathrm{fitness}(\theta_t;\ \tau_t)\big),\qquad \text{频率：每 10–50 题}$$

- **教师后训练（旧想法，记为 B）**：$\tau$ 是**模型权重**，更新在**参数空间**里发生：

$$\tau_{t+1} = \mathrm{PostTrain}\big(\tau_t;\ D_t\big),\qquad \text{频率：每 } G\gg 1\ \text{学生代}$$

## 1. 维度对比（严格）

| 维度 | A：教师进化 | B：教师后训练（旧想法）|
|---|---|---|
| 更新空间 | 提示/规则/配置（壳） | **权重/表征**（核心） |
| 数据形态 | 标量 fitness（学生表现） | **结构化样本**（合法证明+引理+轨迹） |
| 频率/成本 | 中观、低开销 | 宏观、昂贵（GPU 训练日级） |
| 可塑性 | 低（只变“说话方式”） | **高**（可以学会“概念提炼、新型题、元推理”） |
| 跨题迁移 | 弱（策略壳） | 强（权重沉淀“怎么教”的共性） |
| 污染风险 | 低（不进入权重） | **高风险**（见 §2） |
| 响应性 | 快 | 慢（反应延迟 = G 代） |

## 2. B 的高风险点（必须正视）

1. **迎合漂移（compliance drift）**：若 D 全为学生 rollouts，教师会**过拟合学生当前解决模式**——“不出学生不会的题”而表观上“学习进步”变好。教师必须**不仅学学生成功，也学“学生为什么失败”**（失败模式摘要 $\supset$ D）。
2. **保真度坍缩**：学生越强，rollouts 的“难题占比”越低 → 教师学到的“难题先验”被稀释 → 教师退化（只会出“学生已会”的题）。对策：**课程光谱保留**——D 里保留旧难题/未解难题样本（多样性正则）。
3. **奖励黑客/概念盗窃**：教师若用 RL 且目标=学生 LP，会学“偷师”（下题目=学生刚学过的变体）。对策：教师 RL 的奖励只用**长期** LP（低频率，跨学生代）且必须过滤内核验证数据；或直接 SFT 为主（无奖励黑客面）。
4. **教师-学生共同过拟合（双面自锁）**：B 制造“相互捧场”的风险比 A 更严重（A 只改壳，B 改表征——表征层“共同偏好”会固化）。对策：**多版本学生评估**（教师 fitness 对 2–3 个学生代版本平均），这等价于“考试委员会”。

## 3. 理论定位

- **B 的本义**：教师从学生的**合法经验**里**蒸馏教学能力**——它实质上是一种 **transductive transfer（跨智能体迁移）**：把“学生可解问题的分布”迁移为“教师的教学先验”。与 AlphaGo 论文中“监督学习（KGS 人类棋谱）→ 自博弈”的分段**同构**：SFT 后训练 = 让学生/教师吸收已验证的外部经验。
- **A 的本义**：教师**在高频但浅层**适配——它是“教学策略的在线搜索”（neural prompt space），不改善表征，但能快速回应学生状态。
- **两者的数学关系**：A 是 B 的“瞬时算符”，B 是 A 的“慢变量”。严格地讲：

$$\tau_t = \underbrace{\mathrm{evo}\big(\underbrace{\mathrm{post\_train}(\tau_{t-1}, D_{t-1})}_{\text{慢变量(权重)}}, \text{近期反馈}\big)}_{\text{快变量(配置)}}$$

  即 **B 提供“能力基调”，A 提供“风向调节”**。

## 4. 结论与建议（两层教师的最严格形态）

1. **旧想法（B）不是错误的，而是“更接近真教师”的**——因为真正的教师更新的是“理解”（对题/概念/学生的模型），不在“提示”。
2. 但 B 单独使用存在**三条确定的退化路径**（迎合、保真度坍缩、共同过拟合），因此**必须与 A 合成双层**：
   - **权重层（低频，B）**：每 $G$ 代用 $D_t$（合法证明+引理+失败摘要+课程光谱保留）做 SFT (+ 可选 DPO/低温和 RL 仅跨代 LP)；
   - **配置层（高频，A）**：权重不变，按近 10–50 题反馈做 prompt/算子进化（轻量）。
3. **监管规则（防污染/防退化，硬约束）**：
   - 教师训练数据只含**内核验证通过**的样本 + 显式标注的失败模式（不学“半成品推理”）；
   - 教师 fitness 用**多版本学生平均**（试卷委员会）；
   - 课程光谱留存量保证（旧疑难样本比例 ≥ 一定量）；
   - 每代教师发布前跑“教学盲测”（新颖度/难度对抗检查）。
4. **最终判定**：两者不互斥——**B 为主、A 为壳、验证器为闸、多版本评估为委员会**——才是“师生共进化”的稳健形态；与上一文档（12）的“教师进化”并不矛盾，而是它的低频参数空间版本。总架构呈现**三时间尺度**（学生 RTTT 微秒/教师 A 中观/教师 B 宏观），完全符合“人类教师”的真实更新节奏（教案学期级 + 课堂反馈即调）。

> 与 12 号文档关系：12 讨论“进化作为唯一教师更新通道”，本文件论证“进化+后训练双层”，并补充“污染-退化”三道防线。
