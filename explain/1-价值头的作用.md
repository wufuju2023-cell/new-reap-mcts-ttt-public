# 价值头（Value Head）的作用

## 1. 形式化：把“证明搜索”嵌入为一个 MDP

定义状态空间 $\mathcal{S}$ = 证明状态（上下文 + 单一/多目标），动作空间 $\mathcal{A}$ = 候选 tactic 串，环境 = Lean 证明器：

- 转移 $T(s, a) = s' = \mathrm{apply}_{\mathrm{Lean}}(s, a)$（合法时），吸收终态 $s_{\top}$ = 证明闭合并通过内核检验（$\mathrm{checkProof}=\mathrm{ok}$）；
- 奖励 $r: \mathcal{S}\times\mathcal{A}\to\mathbb{R}$ 为稀疏终止奖励：

$$r(s,a) = \begin{cases} 1 & s' = s_\top \\ 0 & \text{otherwise}\end{cases}$$

则“求解质量”可写成折扣回报期望。给定策略 $\pi(\cdot\mid s)$ 与折扣 $\gamma$，**状态价值函数**为：

$$V^{\pi}(s) = \mathbb{E}_{\pi, T}\!\left[\sum_{t\ge 0}\gamma^{t} r(s_t, a_t)\;\middle|\; s_0 = s\right]$$

最优价值 $V^{*}(s) = \max_\pi V^{\pi}(s)$ 恰好度量“从 $s$ 出发的**可证概率**”（$\gamma\to 1$ 时等于求解率）。

**价值头** $V_\phi: \mathcal{S}\to\mathbb{R}$ 就是对该 $\approx V^{*}$ 的**参数化回归近似**。

## 2. 它在 MCTS / 搜索引擎中的角色

树搜索对选择的量是 **PUCT**（与 AlphaZero/config 相同结构）：

$$a_t = \arg\max_a \left[ Q(s,a) + c(N)\, p(a\mid s)\, \frac{\sqrt{N(s)}}{1+N(s,a)} \right]$$

其中 $p(a\mid s)$ 来自策略网络（prior），而 **$Q(s,a)$ 来自价值函数**：叶子展开后

$$Q(s,a) \leftarrow (1-\alpha)\,Q(s,a) + \alpha\,\big[\, r + \gamma\,V_\phi(s')\,\big]$$

并将 $\min/\max$ 语义按 OR/AND 节点聚合（AND 节点等于可解 min 聚合，见 `Tactic/TreeSearch.lean` 的 `backupValueTowardsMin`）。

**严格断语**：

> 若 $V_\phi \equiv \mathrm{const}$（退化），PUCT 的 $Q$ 项退化为零，搜索仅靠 $(p, N)$ 的探索-利用平衡——回报预期完全无法区分“有前途分支”与“死胡同”，样本复杂度（单题所需节点数）随子树大小近似线性退化。

价值头解决的是：在预算 $B$（节点上限）内，把扩展集中在 $V^{*}$ 高的区域，使估算求解率 $\mathrm{solve@}B$ 提高。它是认知型启发式，等价于 AlphaProver 的“值引导”。

## 3. 目标与学习信号

- **离线初始化**（本项目已实现）：二分类目标 $\hat y = \mathbb{1}\{\mathrm{checkProof}(s,a)=\mathrm{ok}\}$：

$$\mathcal{L}_{V}(\phi) = \mathbb{E}_{(s,\hat y)\sim \mathcal{D}}\big[\tfrac{1}{2}\|V_\phi(s)-\hat y\|^2\big]$$

- **在线（RTTT 内）**：TD(0)/蒙特卡洛目标

$$\delta_t = r_t + \gamma V_\phi(s_{t+1}) - V_\phi(s_t),\qquad \mathcal{L}_{\mathrm{TD}} = \mathbb{E}[\delta_t^2]$$

在单题搜索期，价值头以搜索本身的 backup（$G_t$）为监督，执行

$$V_\phi(s) \leftarrow V_\phi(s) + \alpha_V\big(G_t - V_\phi(s)\big)$$

这与策略 LoRA 是**两套参数、两类信号、两种时间尺度**：策略管“提什么动作”，价值管“这状态值不值得继续扩”。

## 4. 参数化（本项目实现）

- 共享 backbone：7B 策略网络冻结/正交 LoRA，取最后层隐向量 $h_\theta(s)$；
- 头：2 层 MLP $V_\phi(s) = W_2\,\mathrm{SiLU}(W_1 h_\theta(s))$（4096→256→1），标量输出；
- 与“聊天式价值模型”（LLM 输出 JSON `{"score"}`）的区别：后者是概率式/非微调大模型的文本采样近似，**不可微、不可在线更新**；$V_\phi$ 是**可微分回归器**——可沿 TD 目标做梯度更新（这正是我们把它放在 `/ttt_step` 里、在“调用期”持续微调的原因）。PUCT 里引入 $V_\phi$ 后，价值信号的偏好（分数）随解题分布自校准。

## 5. 一句话总结（语义上）

价值头近似“**当前证明状态的可证性势函数**”：它不决定下一步做什么（那是策略），而是决定**继续投入搜索是否划算**。在 RTTT 语境下，价值头每接收一次真实 Lean 判证回馈就做一次回归修正，效果是**把搜索对“好分支”的信任不断向本次真实验证结果对齐**——这就是“值引导 + 测试时微调”的核心耦合点。

# 价值头与围棋“胜率”：精确对应关系

## 1. 先纠正一个常见措辞：围棋 AI 的“每种走法的胜率”有两种来源

在 AlphaGo/AlphaZero 谱系里有两个不同对象：

| 对象 | 形式 | 语义 |
|---|---|---|
| **策略网络（policy head）** | $\pi_\theta(a\mid s)$，每个走法一个概率 | “某局面下**该走哪步**的生成先验” |
| **价值网络（value head）** | $V_\theta(s)$，**一个标量** | “该局面→在后续双方最优下**最终获胜的概率**” |
| （由此派生的）**Q 估计** | $Q(s,a) = r + \gamma V_\phi(s')$ | “**该走法之后局面**的胜率估计” |

你记忆中的“每种走法的胜率”**更精确属于 $Q(s,a)$**——它是儿童节点价值 $V(s')$ 经回传得到的边价值；而**可学习、可微、参与训练的核心对象是 $V$**（AlphaZero 中 $V$ 与 $\pi$ 共享骨干形成“双头网络”，并完全替代了旧版 AlphaGo 的随机 rollout 估计）。所以在专业语义下：**价值网络是对“状态”的胜率估计，边价值（对“走法”）是它的投影**。

## 2. 围棋 ↔ Lean 的严格同构

| | 围棋 | Lean 证明 |
|---|---|---|
| 状态 $s$ | 盘面+历史 | 证明状态（目标/上下文/子目标） |
| 动作 $a$ | 落子 | 一条 tactic 串 |
| 转移 | 规则确定 | Lean 内核确定（语法/类型检查判定合法性） |
| **奖励** | **终局唯一信号 ±1（稀疏！）** | **终局唯一信号 $\{0,1\}$（sparse reward）**：$r=1 \iff \mathrm{checkProof}=\mathrm{ok}$ |
| $V(s)$ 的物理解释 | 该局面最终获胜概率 | 该目标“在最优搜索策略下被证开”的概率（$\gamma\to 1$ 时 = 可证率） |

两个领域共享同一核心数学对象：**稀疏终止奖励下的状态价值函数**——这正是你直觉上“感觉它们是同一件事”的本质原因。

## 3. “价值头训练得越好 ⇒ 短期一步选得更准”——严格陈述

这句话在机制上**不完全等价于“决定生成哪一步”**，两个角色要分开：

- **“生成哪些候选”** → 由策略网络承担（prior $p(a\mid s)$ 划定候选化空间）；
- **“这批候选里选哪个继续扩展/提前终止”** → 由 PUCT 机制承担，其中 $Q$ 项（即 $V_\phi$）起决定性作用：

$$a_t = \arg\max_a\Big[ Q(s,a) + c\,p(a\mid s)\frac{\sqrt{N(s)}}{1+N(s,a)}\Big],\qquad Q(s,a) \simeq r + \gamma V_\phi(s')$$

所以**准确的表述**是：

$$\boxed{\text{价值头更准 ⇒ 搜索分配（选择）更准确地按“可证性期望”排序 ⇒ 同等节点预算 } B \text{ 下 solve@}B \text{ 上升（样本复杂度下降）}}$$

它**不直接生成**动作（那是 policy），而是**提前终止“没前途分支”、优先深耕“有前途分支”**——把 1 的终局信号**稠密化为中间状态的连续期望**，从而显著缓解稀疏奖励下的**信用分配问题**（credit assignment hard）。这在专业上称为 value-based guiding 对 search 的“剪枝/定向”作用，正是 AlphaZero→AlphaProof 一脉相承的机制。

## 4. 与我们项目的两点差异（专业上要注明）

1. **网络结构**：AlphaZero 是**共享骨干单网络双头**（联合训练，价值梯度影响表示）。我们当前 phase：backbone 冻结，仅 $\phi$（vhead）+策略 LoRA 分别更新——等价于“weakly coupled two-head”，搜索效果优于纯 prior（$Q\equiv 0$），但表示层不因价值目标而重构。后续若要更贴近 AlphaZero 语义，可打开 backbone 联合训练（成本更高，需先权衡）。
2. **生成侧**：Lean 的候选由**生成式 LLM policy**（词法上属于生成式策略，而不是 Go 的逐点 softmax $\pi$）——但价值头的数学作用不变：**它评估的是“状态的可证势”，与策略如何采样解码无关**。因此“策略生成 + 价值评价”的二分与前面对照完全成立。

## 5. 结论（给你的直觉一个严格版本）

> 是的——在“奖励稀疏 ⇒ 需要价值头来稠密化 + 定向搜索”这个意义上，围棋 AI 与 Lean 证明器是同一类问题；价值头训练越好，PUCT 对“短期下一步”的**分支排序**越接近真实可解排序，树的期望深度/宽度预算性价比越高。但你描述中的“每种走法的胜率”严格对应的是**边价值 $Q$**（由价值头在其 child 状态上的投影），而可学习对象、RTTT 中可微更新的对象是状态价值 $V_\phi(s)$。在 RTTT 语境下，价值头按 TD 目标 $V_\phi(s)\leftarrow V_\phi(s)+\alpha_V(G_t-V_\phi(s))$ 随每次真实判证回馈调整——既收缩“对分支好坏”的错误估计，也**在单题搜索的中途**让“值导向”的排序向真实验证看齐。
