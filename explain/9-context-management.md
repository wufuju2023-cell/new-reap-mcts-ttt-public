# 9｜链式任务的上下文管理（Memorization 与窗口预算）

> 归档：初始提问 + 严格分析。问题：多题链式训练（题 A → MCTS+PV+RTTT 更新 → 结果进库 → 题 B…）中，轨迹越来越长，上下文管理是否成为本质问题？

## 0. 先破题：四个“上下文”，只有一个会线性膨胀

| 类别 | 载体 | 增长方式 | 是否爆炸 |
|---|---|---|---|
| ① 窗口上下文（LLM 输入 prompt） | 策略/价值网络输入 | 取决于注入策略 | **潜在真问题** |
| ② 搜索树状态（MCTS 节点） | 各节点 Lean saved state + obs | 树增节点；局部 | 不依赖链长 |
| ③ 外部库 $L$（mathlib 增长） | 向量库/检索索引 | $\|L_n\|$ 无限增长 | 不占窗口（索引化） |
| ④ 跨题轨迹/工具输出 | 情景记忆（trajectory log） | 随链线性 | 可压缩为摘要 |

## 1. 形式化：三个不变量 ⇒ 窗口 $O(1)$

**(I1) 每步窗口恒定**：
$$W_{\mathrm{step}} = w_0(\text{当前目标}) + w_1(\text{检索 top-}k) + w_2(\text{上题摘要}) + w_3(\text{短程}) \le W_{\max}$$
其中 $w_1,w_2$ 为常数上限（$k$ 固定、摘要 token 上限固定），与题号 $n$、$\|L_n\|$ **无关**。

**(I2) 跨题“原子化沉淀”，不做整轨搬运**：
$$T_{n-1} \to \mathrm{mem}(T_{n-1}) = \{\text{定理, 关键引理, 未证猜想, 失败模式, 灵感登记}\}$$
证明过的进 $L$（③）；未完成但“有用线索”登记为 hypothesis/insight/revision 型 memo；原始 trace 归档弃置。

**(I3) 树状态 Markov 化**：节点价值只依赖 (goal, local ctx, obs-历史窗 $O(1)$)，树搜索不把全历史带在节点间。

若 (I1)-(I3) 成立：
$$\|H_n\| \to \infty\ (\text{研究史}),\quad \|W_{\mathrm{step}}\| \le W_{\max}\ (\text{每步窗口})$$

## 2. 剩余本质风险（诚实清单）

**(A) 压缩损失**：关键启发式线索可能在摘要被剪掉。
→ 对策：多粒度记忆（摘要只供 prompt；原始证据全量归档可检索；未证实直觉登记为 memo，不经过摘要压缩）。

**(B) 检索信噪比退化**：$\|L_n\|$ 增大 → top-$k$ 相似度平均下降。
→ 对策：渐进检索 + 难度分层索引（“高层引理”与“低层引理”分池）。

**(C) 链式状态迁移成本**：把上一题“整轨”搬进下一题 prompt 会人为放大 (A)(B)。
→ 正确做法：分子化（定理/引理/日志），这要求“链上信息原子化”，而非链本身长度。

## 3. 与 RTTT 的特殊交互

- RTTT 梯度 buffer 是短窗（每 $k$ 验证事件一步），与链长无关。
- 价值头跨题经验是**程序性记忆**（存权重），不占窗口，只更新不膨胀（“技能不占工作记忆”类比）。
- 留意：链中持续在线学习可能带来**非平稳价值漂移**（任务分布漂移）——不是上下文问题，处理靠题型分组批量更新 + adapter snapshot/rollback（已有）。

## 4. 面向 V2 的记忆子系统模块

| 模块 | 功能 | 对应记忆类 |
|---|---|---|
| `MemoRegistry` | `(id, type[fact/hypothesis/insight/revision], content, refs)` | ④ 原子化 |
| `Retriever` | 语义索引进 memo/定理库，返回 top-$k$ | ③ |
| `SummaryComposer` | 每题结束生成 ≤$w_2$ token 研究日志 | ④→摘要 |
| `WindowBuilder` | 恒定预算组合 (w0+w1+w2+w3) | ① |
| `TreeStore` | 节点局部 saved-state（Lean 原生支持） | ② |
| `RTTT Buffer` | 短窗在线更新 | 程序性记忆（权重） |

规模诚实估算：$|L_n| \sim 10^5$ 引理 × 每引理 ~200 token → $10^7$ 向量，Embedding 检索毫秒级；摘要/管理为 $O(n)$ 写、$O(w_2)$ 读——**瓶颈在生产（摘要/检索）而非窗口**。

## 5. 结论

1. 是问题，但**不是“窗口爆炸”型问题**——满足 (I1)-(I3) 后链长对上下文 $O(1)$；要求“跨题不搬原轨迹，只搬分子化产物”。
2. 剩余本质风险=(A) 压缩丢失灵感（用不摘要化 memo + 原始证据可检索兜住）+(B) 检索退化（难度分层索引）。
3. “链越长越难”的真相：不是“窗口装不下”，而是**记忆系统的生产质量**（摘要/检索）成为瓶颈——属于“记忆体系设计问题”，可与“库增长律 $d_g$ 与 $\mu$”统一观测。
